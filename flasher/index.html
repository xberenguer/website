BEFORE YOU CONNECT

How to flash your device

1. Use a data cable

Connect one supported device. Close serial monitors and other flash tools, then follow the recovery-button instructions shown for your model.

2. Review and prepare

The installer checks the chip, flash size and firmware hashes, then saves the flash sectors it will replace. Download that recovery file before installing.

3. Install and check

Keep USB connected. The written bytes are verified before reset. Check the screen and buttons afterward; byte verification does not test physical operation.

What gets replaced?

Installing restarts your device and replaces its current application. Save any seed you need first: a flash backup does not preserve a seed held in RAM.

StickS3 installs the selected bootloader, partition table, startup metadata and application, plus game assets when needed. The NVS region is skipped; application state is not guaranteed to transfer between projects. Waveshare installs only the application and requires its matching factory partition map. Whole-chip erase is never used.

Recovery and connection help

If connection fails, use the model's flashing-mode instructions, a different data cable or USB port, and close other serial apps. After a failed write, keep the recovery file. Reconnect the same device in flashing mode and choose Restore a backup. The file is checked against the device identity and allowed flash ranges.

Automatic recovery is attempted when communication remains available. A disconnected cable, closed tab or power loss can prevent it. Recovery backups stay on your computer and can contain private device data; do not post them publicly.

Project manual Source / build notes

Hashes, signatures and Secure Boot

The browser verifies an Ed25519 signature on the release catalog using its pinned public key, checks each firmware download against the signed SHA-256, then verifies written flash bytes with device-side MD5. Installation is blocked if signature or hash verification fails. This does not enable Secure Boot or change device eFuses.

Seeder credits and verification

Original Seeder by BitMaker, from an idea by Lunaticoin. The community fork adds StickS3 and Waveshare hardware ports and documents every deviation. Build and verify independently for a seed device; this page and its checksums come from the same website.

Downloads, source and notices

The exact versions, file sizes and SHA-256 hashes are visible in each project's installation panel and in the catalog. Download checksums. Browser flash transport is pinned to Espressif esptool-js 0.7.1, with noble-hashes 2.0.1 for protocol MD5. Licenses and credits.
